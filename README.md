### Hi, I'm Karina

Cloud engineer in Spain. I build **[VPC Atlas](https://vpcatlas.com)**: an open-source command-line tool that
discovers an AWS network (VPCs, subnets, routing, Transit Gateway, peering, endpoints and the edge services)
and draws it as draw.io or Lucid diagrams, with a dashboard to browse the result.

- macOS / Linux: `curl -fsSL https://vpcatlas.com/install.sh | sh`
- Windows: `irm https://vpcatlas.com/install.ps1 | iex`
- Docs: https://vpcatlas.com/docs/ · Source: https://github.com/karina-pp/vpcatlas
